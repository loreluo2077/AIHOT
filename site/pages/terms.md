页首说明：

> 本站聚合公开信源，用模型生成中文标题、摘要与精选，原文版权归各来源所有。网页、RSS、公开 API 与 MCP 均可匿名使用，不需要注册。

## 1. 内容与版权

本站展示的标题、摘要和推荐理由由模型根据公开来源生成，可能有误，重要信息请以原文为准。原文版权归各来源所有；站内只在来源明确允许时展示全文，其余只展示摘要和原文链接。

本站的焦虑指数与热词是站在公开信息之上算出的二次结果，用来描述"今天讨论的热度"，不代表对任何事件、产品或公司的评价，也不构成投资建议。

## 2. 来源方的更正与下架

如果你是来源方，希望更正、下架或调整展示方式，请通过反馈页联系我们，我们会尽快处理。

## 3. 使用本站的数据

网页阅读、RSS 订阅、通过公开 API 与 MCP 读取数据，都允许个人使用与组织内部使用，不需要事先取得同意；请保留出处链接。

以下用途需要事先取得我们的书面同意：把本站内容整体或大批量转载、再分发；把本站数据用于训练模型或构建数据集；把本站内容包装成商业产品对外提供。

## 4. 接口与频率

RSS、公开 API 和 MCP 为匿名只读接口。请按响应中的缓存时间轮询，遇到 429 请遵守 `Retry-After`，不要并发重试。给 Agent 用的说明在 [Agent 接入页](/agent)。

## 5. 焦虑指数、热词与社区信号

任何人都可以给当天的焦虑程度投一票、补充一个热词，或发一条社区信号，不需要注册。

社区信号是公开内容：请保持真实、与 AI 行业相关，不要提交广告、人身攻击、隐私信息、违法内容或
不希望被公开的内容。为了限制滥用，一人 5 分钟只能发一条、一天最多 5 条；其他人可以认同或举报，
**被两个不同的人举报会自动隐藏**，我们再决定是恢复还是删除。热词与信号我们都保留隐藏或删除的权利。

投票、热词与信号都只是读者对当天讨论热度的看法，不构成任何建议。

## 6. 站外服务

本站介绍或链接的 AI 服务（例如接口中转）由各自的运营者提供与销售，我们不是这些服务的提供方，不参与其交易，也不对其可用性、价格和数据处理负责。使用前请阅读对方的使用条款与隐私说明。

## 7. 免责

本站按"现状"提供，不保证内容完整、准确和持续可用。
